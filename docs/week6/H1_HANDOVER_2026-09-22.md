## Kiểm tra trước review

Chạy từ gốc repository:

```powershell
python -m scripts.validation.verify_week6_t1_freeze
python -m scripts.validation.verify_week6_h1_freeze
python -m scripts.testing.run_full_tests
git diff --check
```

Verifier PASS chỉ chứng minh integrity của gói bàn giao, không phải review
độc lập hoặc GO mở evaluation. Xem kết quả chạy thực tế trong
`H1_VALIDATION_2026-09-22.json`. Các test số bổ trợ chứng minh, không thay thế
kiểm chứng giả thiết hoặc confirmatory experiment.

Máy H1 không có pdflatex/bibtex. Pandoc đã parse nguồn LaTeX nhưng không thay
thế typesetting. **PDF đang tracked là bản cũ**: Linh cần build nguồn mới trên
Overleaf, kiểm lỗi, hình/bảng và page budget trước tích hợp. Không báo PDF PASS.

## Đẩy lên nhánh Hưng

Không dùng `git add .`. Chỉ stage các file H1, tài liệu đã sửa và metadata
checksum r1 xuất hiện trong diff; không stage `datasets/` hoặc PDF cũ.
Kiểm `git diff --cached --stat` và `git diff --cached --name-only` trước commit.
Sau commit:

```powershell
git push -u origin docs/h1-v4e-formula-freeze
```

PR title: `docs: freeze OEH-v4E formula and theory (H1)`.
PR ghi rõ T1 r1 là re-anchor checksum tới nội dung Git đã công bố, PDF chưa
build local, evaluation chưa mở, và cần Linh/B2 review. Không tự merge main.
