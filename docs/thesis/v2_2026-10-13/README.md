# Thesis v2 (13/10/2026)

Six chapters following the agreed thesis structure: Introduction; Theoretical
Background and Problem Definition; Dataset and Data Generation; Method and
Evaluation Design; Results and Discussion; Conclusion and Future Work. The
references and appendices (108-column lineage, access matrix, protocol and
amendments, evaluation history, artifacts) are generated from the same sources.

| File | Role |
|---|---|
| `00_front.md` … `08_appendix.md` | Maintained Markdown sources (English) |
| `07_references.md` | Keyed reference list; `[@key]` citations are numbered by first use |
| `figures/` | Figures generated by `scripts/analysis/export_manuscript_tables_20261013.py` and `scripts/figures/build_oeh_pipeline.py` |
| `template/DAORL_thesis_template.docx` | School template (cover page and styles) |
| `build_thesis_v2.py` | Builds the DOCX: cover from the template, native Word equations, tables, figures, captions |
| `update_fields.ps1` | Opens the DOCX in Microsoft Word, fills the table of contents and caption lists, exports the PDF |
| `DAORL_Thesis_v2_2026-10-13.pdf` | Current review build (45 pages) |

Build (Windows, Microsoft Word installed):

```powershell
python -m pip install latex2mathml python-docx lxml
python docs/thesis/v2_2026-10-13/build_thesis_v2.py
docs/thesis/v2_2026-10-13/update_fields.ps1 -DocxPath docs/thesis/v2_2026-10-13/DAORL_Thesis_v2_2026-10-13.docx
```

The DOCX is a build product and is not committed. Every number in Chapters 3–5
comes from sealed artifacts through the manuscript export script; do not edit
numbers by hand. Still to do before submission: confirm the thesis language with
the faculty, final author/supervisor details, and supervisor review.
