# BRIDGE expanded follow-up: scope, data and live run (2026-10-08)

## What is being compared

The [published BRIDGE v1.1.1 dataset](https://zenodo.org/records/12556298) contains 155 sticky-action MDPs. The [author repository](https://github.com/cassidylaidlaw/effective-horizon/tree/main/data/bridge_dataset) identifies 67 Atari, 55 Procgen and 33 MiniGrid MDPs. The [original stochastic effective-horizon paper](https://aima.cs.berkeley.edu/~russell/papers/iclr24-horizon.pdf) evaluates **online** sample complexity for PPO, DQN, SQIRL and GORP. The current project evaluates a different endpoint: the seven-category **offline** data requirement of BC, CFQI and IQL from an independent pilot. Therefore this run can test transfer to published MDPs and rank original scalar difficulty signals against that endpoint; it cannot be presented as a reproduction of the paper's 155-MDP online table.

A [read-only audit of all 155 published metadata rows](../../benchmarks/bridge/expanded_panel_2026-10-08/published_155_online_metadata_audit.json) found finite sample-complexity counts of PPO 96, DQN 76, SQIRL 69 and GORP 27 in the v1.1.1 CSV. These differ from Table 2 of the ICLR 2024 paper (98, 78, 77, 29), and its Table 3 pairwise statistics also differ from a direct CSV calculation. Thus even the author metadata must not be relabelled as an exact paper reproduction without resolving the version/field differences. This audit never reads OEH labels.

## Frozen protocol and running pipeline

The [new protocol](../../benchmarks/bridge/expanded_panel_2026-10-08/protocol.json) was frozen before any new learner labels. It retains the previous five-task follow-up's five behavior families, ten learner seeds, six data budgets plus `>x50`, threshold `0.95`, 64 posterior draws, 10 posterior seeds, and task-specific published horizons. The pipeline checks 75 prelabel probability rows per forecaster and 25 original scalar-score rows before allowing one label pass. OEH is compared on the same rows with B2, an adapted published XGBoost-CF survival formulation, and a 108-input architecture control. EH/ERI/TQ/SACo remain scalar secondary rank comparisons, with their distinct information access disclosed.

The 25 pilot streams are sealed at `datasets/bridge_v1_1_1/offline_pilot_expanded_2026-10-08/manifest.json`. The [live watcher](../../benchmarks/bridge/expanded_progress_watch.ps1) updates `artifacts/week8/bridge_expanded_live_status_2026-10-08.json` every 30 seconds with per-stage checkpoint counts and whether the pipeline is still running. A `COMPLETE` phase requires the analysis manifest; a `NO_GO` phase preserves completed checkpoints and the failure log.

A [prelabel implementation addendum](../../benchmarks/bridge/expanded_panel_2026-10-08/prelabel_implementation_addendum.json) records an exact runtime acceleration for the authors' SACo unique state–action count on one-hot tabular observations.
