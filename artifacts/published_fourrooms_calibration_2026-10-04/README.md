# Published FourRooms component test

Source: [Farama Minari D4RL/minigrid/fourrooms-random-v0](https://minari.farama.org/datasets/D4RL/minigrid/fourrooms-random-v0/). This is a third-party published offline trajectory dataset, not a dataset generated by this project. The local HDF5 SHA-256 and the episode-ID split are pinned in `protocol.json`; the large HDF5 file is omitted from Git.

The protocol reserves 990 episodes for fitting and 2,084 for one test, leaving 7,100 unused. It predicts the next local object category from a 3x3 visual patch using an empirical-Bayes Dirichlet transition model versus maximum likelihood and Krichevsky–Trofimov smoothing. The visual observation is partial, so the test probes a component of OEH under transfer. It does **not** validate the full learner-specific tabular requirement forecast.

The four-contrast gate in `result.json` is **NO-GO**. Empirical Bayes beats KT on both scores with positive simultaneous lower bounds, but it loses to MLE on Brier and has a negative simultaneous lower bound on log-loss gain against MLE. The test set was used once; no tuned re-test on it is reported.
